# gympo

Sitio web de **GymPo**, la app para registrar tus entrenamientos, rutinas,
medidas y fotos de progreso.

Publicado con **GitHub Pages** en el dominio [gympoapp.com](https://gympoapp.com).

## Estructura

| Archivo | URL | Contenido |
|---|---|---|
| `index.html` | `https://gympoapp.com/` | Landing page promocional |
| `privacy.html` | `https://gympoapp.com/privacy.html` | Política de Privacidad |
| `CNAME` | — | Dominio personalizado para GitHub Pages |
| `.nojekyll` | — | Sirve el HTML sin procesar con Jekyll |

Las páginas son HTML autocontenido (CSS embebido, sin dependencias externas).
